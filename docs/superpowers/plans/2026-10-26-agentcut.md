# agentCut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native macOS menu-bar app: you select text, press a global shortcut (or use right-click → Services), and a small bubble under the text streams a ready-made fix from the Claude Code or Codex CLI. You can then Replace the selection with it or Copy it.

**Architecture:** All testable logic lives in a local Swift package, `AgentCutCore`: settings, prompt building, the incremental response parser, CLI discovery, the process runner, the providers, the bubble view model and the bubble placement math. A thin AppKit/SwiftUI app target generated with XcodeGen holds whatever needs the OS: the menu bar item, the non-activating panel, Accessibility reads, synthetic ⌘C/⌘V, the Services provider, the global hotkey, the settings window and onboarding.

**Tech Stack:** Swift 6.2, SwiftUI + AppKit, macOS 14+, Swift Testing (`import Testing`), XcodeGen (`/opt/homebrew/bin/xcodegen`), [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts) 2.x, `SMAppService` for launch at login.

**Spec:** `docs/superpowers/specs/2026-10-26-agentcut-design.md`

## Global Constraints

- macOS deployment target **14.0**; Swift language mode **6**.
- **No API keys.** Only the user's authenticated `claude` and `codex` CLIs, launched as child processes.
- **App Sandbox OFF.** The app needs Accessibility, Services and child processes, so it ships outside the App Store. Hardened runtime ON.
- Signing: `Developer ID Application: Dorjan Rudaj (S4H5J5QWU7)`, manual signing, team `S4H5J5QWU7`. A stable identity keeps the Accessibility permission across rebuilds.
- Bundle id `com.dorjanrudaj.agentcut`, product name `agentCut`, `LSUIElement = YES` (no Dock icon).
- The agent only **answers with text**. Claude runs with `--tools ""`. Codex runs with `-s read-only --ephemeral`. Both run with cwd `~/Library/Application Support/agentCut/work` (an empty directory).
- Both CLIs receive the prompt on **stdin** (verified: `claude -p` reads stdin, `codex exec … -` reads stdin).
- Request timeout: **60 s**. Esc cancels and terminates the child process.
- Latency target for v1: **5–6 s total is acceptable, as long as text appears progressively** (Claude streams; Codex delivers the whole message at the end).
- UI copy is in **Italian**.
- Default global shortcut: **⌃⌥Space**.
- Git: initialise the repo in place on the default branch. Do **not** create branches or worktrees (user rule).

## Review Focus

1. **Huge selection** (e.g. 2 MB of logs): truncate the input to 20 000 characters and tell the model it was truncated. The app must not freeze and argv must not blow up (it doesn't: input goes through stdin). → Task 3 test `truncatesLongInput`.
2. **The model ignores the response format** (no `KIND:` header, or `---` inside the code body): show the raw text as an `answer`, and split only on the first `---`. → Task 3 tests `fallbackWithoutHeader`, `onlyFirstSeparatorSplits`.
3. **CLI exits non-zero, prints "Not logged in", or hangs**: the bubble shows a specific Italian error, never spins forever. → Task 4 `nonZeroExitThrows`, `timesOut`; Task 5 `claudeNotLoggedInMapsToNotAuthenticated`.
4. **Shortcut pressed again, or Esc, while a request is running**: the previous child process is killed and no orphan `claude` is left. → Task 4 `cancellationTerminatesProcess`; Task 7 `cancelStopsStreaming`.
5. **Clipboard holds non-text data (an image or file) when we borrow it for ⌘C/⌘V**: every type of every item is restored afterwards. → Task 6 `restoresAllTypes`.

**Response protocol (my call; the spec left the format to the builder).** A line-based format, chosen because it streams well, unlike JSON:

```
KIND: replace|answer|unclear
LABEL: <short label, e.g. SQL · errore di sintassi>
NOTE: <one-line explanation of what changed>
---
<body: the ready-to-paste solution, or the answer text>
```

**App system prompt (exact copy; `build` concatenates it, then a blank line, `Lingua delle risposte: <language>.`, and, if non-empty, a blank line + `Istruzioni dell'utente:\n<userSystemPrompt>`):**

```
Sei agentCut, un assistente lampo dentro macOS. L'utente ti passa un testo che ha selezionato (codice, query, dati, prosa) ed eventualmente una domanda.
Se non c'è una domanda: capisci da solo di che testo si tratta e qual è il problema più probabile (errore di sintassi, formato da sistemare, refuso...) e restituisci il testo corretto, pronto da incollare al posto dell'originale.
Se c'è una domanda: rispondi alla domanda. Se la risposta è un testo che sostituisce l'originale usa KIND: replace, altrimenti KIND: answer.
Se non riesci a capire cosa serve usa KIND: unclear e nel corpo scrivi una breve domanda per l'utente.
Non eseguire comandi, non leggere né modificare file: rispondi solo con testo.
Rispondi SEMPRE e SOLO in questo formato, senza testo prima dell'intestazione:
KIND: replace|answer|unclear
LABEL: <etichetta brevissima, es. "SQL · errore di sintassi">
NOTE: <una riga su cosa hai cambiato o perché>
---
<corpo: solo il testo risultante, senza blocchi ``` e senza commenti>
```

**User prompt:** `Testo selezionato:\n<<<\n<input>\n>>>`. If the input was truncated, add `\n(Nota: testo troncato ai primi 20000 caratteri.)`. If there is a question, add `\n\nDomanda: <question>`.

**Parser rules:**
- Accumulate the chunks.
- If the first non-blank line doesn't start with `KIND:` (case-insensitive), switch to fallback: `kind = .answer`, `headerComplete = true`, `body` = all the text so far.
- Otherwise, read `KEY: value` header lines until the first line that is exactly `---` (whitespace trimmed). Everything after that line is the body. Later `---` lines belong to the body.
- An unknown KIND value means `.answer`.
- Until the header is complete, `body == ""` and `headerComplete == false`.
- `finish()`: if the header never closed, return fallback `.answer` with the whole raw text. If the body is exactly one fenced block (```lang\n…\n```), strip the fences. Trim trailing newlines.

**Files:**

**Interfaces:**
- Consumes: `AgentProvider`, `AgentError` (Tasks 4–5), `PromptBuilder`, `ResponseParser`, `ParsedResponse`, `CapturedText` (Task 3), `AppSettings` (Task 2).
- Produces:
  - `public enum BubbleState: Equatable { case loading, streaming(ParsedResponse), done(ParsedResponse), askingQuestion(previous: ParsedResponse?), failed(AgentError) }`
  - `public enum BubbleAction: Equatable { case replace, copy }`
  - `@MainActor @Observable public final class BubbleViewModel`:
    - `init(input: CapturedText, settings: AppSettings, provider: Result<AgentProvider, AgentError>)`
    - properties: `state`, `questionText: String`, `inputPreview: String?` (the first 3 lines of the input, max 160 chars, **only** when `source == .clipboard`), `primaryAction: BubbleAction?` (`.replace` when `done(kind == .replace)`, `.copy` when `done(kind == .answer)`, otherwise nil), `canReplace: Bool` (`primaryAction == .replace`)
    - methods: `start()`, `submitQuestion()`, `cancel()`, `showQuestionField()`
  - Behaviour:
    - `start()` with input that is blank after trimming → `.askingQuestion(previous: nil)`, the provider is not called.
    - A provider `.failure(e)` → `.failed(e)`.
    - Otherwise `.loading`, then `.streaming(parsed)` once `headerComplete`, then `.done(parsed)`.
    - `done` with `.unclear` → `.askingQuestion(previous: parsed)`.
    - A thrown `AgentError` → `.failed`. Any other error → `.failed(.processFailed(exitCode: -1, stderr: error.localizedDescription))`.
    - `submitQuestion()` cancels any running task and restarts with `question = questionText`. The previous response is replaced, there is no history.
    - `cancel()` cancels the Task, which terminates the stream and therefore the process (Task 4).
  - `public enum BubblePlacement { public static func frame(size: CGSize, anchor: CGRect?, mouse: CGPoint, visibleFrame: CGRect, gap: CGFloat = 8) -> CGRect }`: AppKit coordinates. Below the anchor (`anchor.minY - gap - size.height`). If that goes under `visibleFrame.minY`, then above (`anchor.maxY + gap`). x = `anchor.minX`, clamped into `visibleFrame`. A nil anchor → use `CGRect(origin: mouse, size: .zero)`.
  - `final class BubblePanel: NSPanel` (app): style `[.nonactivatingPanel, .borderless]`, `level = .floating`, `isMovableByWindowBackground = true`, `canBecomeKey` true, background `NSVisualEffectView(.popover)` with a 12 pt corner radius. Fixed width **360**, height fitted to the content up to **420** (the body scrolls). It closes on `resignKey` and on Esc (both call `viewModel.cancel()` and then `onClose`).
  - `struct BubbleView: View` (app), matching card A of `popup-layout.html`:
    - the label as a capsule tag
    - the body in a monospaced, selectable `Text` while it streams
    - the note in secondary text
    - for clipboard input, the `inputPreview` in tertiary text with the prefix `"Dagli appunti: "`
    - buttons "Sostituisci" (shown only when `canReplace`, `.keyboardShortcut(.return)`), "Copia" (`⌘C`; it gets `.return` when the primary action is `.copy`) and "Chiedi altro…"
    - in `askingQuestion`, a focused `TextField("Fai una domanda su questo testo…")` that submits on ⏎. When `previous` is `.unclear`, show its body as the hint above the field.
    - `loading` shows a `ProgressView` with `"Sto pensando…"`
    - `failed` shows `error.userMessage` and, for `.notAuthenticated`/`.cliNotFound`, a button "Apri Impostazioni"
    - Closures: `onReplace(String)`, `onCopy(String)`, `onClose()`, `onOpenSettings()`.
